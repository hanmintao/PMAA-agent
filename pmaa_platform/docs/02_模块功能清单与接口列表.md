## 2. 接口列表

基础路径 `/v1`。所有错误统一返回 `{error_code, message, details}`，错误码取自 `domain/enums.py:StableErrorCode`。

### 2.1 导入与参考库

| 方法 | 路径 | 用途 | 关键返回/检查 |
|---|---|---|---|
| GET | `/imports/formats` | **上传支持矩阵**（单一数据源，前端直接渲染） | 支持扩展名、体积上限、拒收清单、注意事项；避免前后端漂移 |
| POST | `/imports/extract` | **从 PDF / Word / 图片反解质谱峰** | 三级策略（文本表格 → 内嵌图片 → 整页渲染）；`mz_min/mz_max` 校准轴；返回预览图 + 可编辑峰表 + 置信度 |
| POST | `/imports/extract/confirm` | 人工校准后确认峰表 | 单谱或 `spectra[]` 多谱批量确认；每张内嵌图生成独立组分，保留图片序号、独立轴范围、标签、`provenance` 与提取参数 |
| POST | `/imports/upload` | **浏览器文件上传**（multipart/form-data） | 支持 .xlsx/.xlsm/.csv/.tsv/.json/.pdf/.doc/.docx/图片；`.doc` 本地转换，压缩包拒收；按 SHA-256 去重 |
| POST | `/imports/preview` | 按服务端路径解析原表并预览 | 布局（表头行/m/z 列/分组行/合并区/隐藏行列）、识别到的语义、逐行化学复核结果 |
| POST | `/imports/commit` | 提交审核通过的导入 | 入库/隔离/分支隔离统计；错误行清单不静默丢弃 |
| POST | `/imports/peak-table` | 导入已积分峰表（JSON 或 `path` 指向 CSV/JSON） | 规范化组分列表 |
| GET | `/references` | 参考条目列表 | 支持 `review_status` 过滤、是否含隔离条目 |
| GET | `/references/{id}` | 单条参考条目（含离子与源单元格） | — |
| GET | `/references/{id}/provenance` | 来源链 | 源文件哈希、源行、离子源单元格、审核轨迹 |
| POST | `/references/{id}/review` | 设置审核状态 | `unreviewed / quarantined / reference_only / locally_validated` |
| GET | `/derivatives` | 化学实体及其**全部**原残基来源 | `multi_origin` 标记多来源 |

### 2.2 样本、方法、保留

| 方法 | 路径 | 用途 |
|---|---|---|
| POST/GET | `/samples` | 建档 / 列表 |
| POST/GET | `/samples/{id}/preparations` | 登记/读取 N1–N10 制备事实；可绑定分析与证据包 |
| POST/GET | `/methods` | 新建方法版本 / 列表（`locked` 表示已被报告引用） |
| POST | `/methods/{id}/retention` | 登记保留观测（RT/RRT/RI，单位自洽校验） |

### 2.3 分析与复核

| 方法 | 路径 | 用途 | 关键检查 |
|---|---|---|---|
| POST | `/analyses` | 创建分析任务并计算候选 | 幂等键复用；返回完整 `ComponentResult`（含 result_contract 全部必填字段） |
| GET | `/analyses` | 任务列表 | — |
| GET | `/analyses/{id}/components` | 组分与候选（不只 Top1） | 分项证据、歧义、冲突、缺失项、建议补测 |
| POST | `/analyses/{id}/reviews` | 人工复核 | 必须填原因；确认类决定必须引用证据 |
| POST/GET | `/analyses/{id}/qc` | 计算样本级 QC | 失败即冻结正式放行，候选保留 |

### 2.4 LLM

| 方法 | 路径 | 用途 |
|---|---|---|
| POST/GET | `/llm/providers` | 配置服务商（密钥只存 `secret_ref`，响应脱敏） |
| POST | `/llm/providers/{id}/test` | 无样本连接与能力测试（不发送实验数据） |
| POST | `/llm/providers/{id}/config` | 修改配置（自动递增 `config_version`，使缓存失效） |
| POST | `/analyses/{id}/llm-assessments` | 请求 LLM 辅助复核（证据包由服务端构建） |
| GET | `/llm-assessments/{id}` | 获取评议与校验结果（原响应、用量、校验明细） |
| POST | `/llm-assessments/{id}/reviews` | 审核 LLM 建议（接受/部分接受/拒绝 + 理由） |
| GET | `/analyses/{id}/llm-assessments` | 某分析的评议列表 |

### 2.5 报告与辅助

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/analyses/{id}/reports` | 导出报告（`fmt=json / html`；QC 失败仅出带标识草稿） |
| GET | `/reports/by-id/{id}` | 按报告 ID 读取不可变历史快照 |
| GET | `/health` | 健康检查与规则版本 |
| GET | `/enums` | 全部枚举与错误码（前端单一来源） |
| GET | `/chemistry/frameworks` | 五种骨架框架定义 |
| POST | `/chemistry/map` | 化学映射规则自检（给骨架与 O-Me，返回连接位与乙酰位） |
