# 甲基化候选排序误诊整改与验收

## 1. 验收案例

已知谱图标注为：

- PMAA：`1,2,3,5,6-Penta-O-acetyl-1-deuterio-4-O-methyl-D-glucitol`
- O-Me：`[4]`
- O-Ac：`[1,2,3,5,6]`
- 原残基取代位：`[2,3,6]`
- 目标化学实体：`Hex|Me4|Ac1.2.3.5.6|NaBD4_CH3I`

用于回放的标注离子为 `59,71,87,100,116,129,143,160,171,189,202,218,231,245,262`；
人工复核强峰为 `87,129,189`。图片峰值属于 `derived_from_image / selected_ions`，不是仪器原始峰表。

## 2. 原复盘中正确与需要纠正的部分

正确：

1. coverage 分子、分母使用不同 boost 基准会造成大于1，必须同源归一。
2. 189 对该参考库中的 4-O-甲基-Glc 很有区分价值，强峰漏标会降低排序稳定性。
3. Top1 与近邻分差很小时不能把第一名当成诊断。

需要纠正：

1. 参考表红色只表示相对强度大于20%，不能统称“signature 离子”。
2. selected-ion 或图片峰表中没有列出某离子，不等于实验未检出，不能据此硬扣分或删除候选。
3. “完整扫描范围”本身不能证明分子离子；不同甲基/乙酰取代数会改变 PMAA 分子量，
   因而 Hex/dHex/Pen 各设一个固定 MW 的硬门控不适用于生产判定。

## 3. 已实施方案

### 3.1 检索层

- coverage 与 precision 分别在参考侧、查询侧自洽归一，均限制在0–1。
- IDF 加权与查询强峰 boost 只用于候选排序，分数不解释为正确概率。
- 参考强峰缺失惩罚只在 `provenance=observed` 且
  `spectrum_completeness=full_acquired_range` 时启用；仍是软降权，不是硬排除。
- 图片、文档、selected ions 一律禁用缺失负证据。
- 最高分低于保守警戒线时，候选保留，但身份降为 `unknown`。
- 前两名绝对差不超过0.05时进入并列带。

### 3.2 证据约束层

- 移除生产流水线中的固定骨架 MW 硬门控。
- 单糖组成默认是软约束；仅在用户明确确认检测方法、标准和检出能力已验证，且组成列表完整时，
  才能删除来源糖与组成完全不相交的候选。
- EI 不能稳定区分的 Gal/Glc/Man 仍以糖组呈现；定种依赖同方法 RI/RT、标准品及其他正交证据。

### 3.3 前端

- 第一行显示为“检索排序首位”，明确标注“不是结构诊断、分数不是概率”。
- 展示前两名分差和并列带。
- “红峰”改称“参考强峰”；“低覆盖”改称“参考稀疏”。
- 图片峰表可逐峰人工修改普通/强峰标记。
- 图片/文档输入锁定为 selected ions，不能在比对页升级成完整峰表。
- 增加“单糖组成列表已验证完整”显式开关。

### 3.4 启动一致性

- 快速启动器使用 `.run/server.pid` 与 `.run/server.port` 管理单一实例。
- 再次双击时先停止受管旧实例，再用当前源码重启，避免浏览器连到未部署的旧进程。
- 健康检查返回应用版本、规则版本、PID 与启动时间。

## 4. 回放结果

| 输入情形 | 正确实体排名 | 分数 | 证据等级 | 缺失负证据 |
|---|---:|---:|---|---|
| 图片推导，87/129/189 标强 | 1 | 0.440 | candidate | 禁用 |
| 仪器完整峰表，87/129/189 标强 | 1 | 0.440 | candidate | 软降权启用 |
| 图片推导，全部按普通峰 | 1 | 0.345 | candidate | 禁用 |

图片全部按普通峰时，第二名得分约0.325，与第一名差约0.021，界面按并列带提示；
即使正确实体排第一，也不能据此签发唯一结构。

## 5. 放行标准

当前代码回归 `100/100` 通过，只说明规定的软件行为可重现。正式科学放行仍需要：

1. 同机、同柱、同温程 PMAA 标准品的完整数值 EI 与 RT/RI；
2. 独立盲测集，预注册 Top-k recall、错误排首率、覆盖率与拒判率；
3. 图片提取与仪器导出峰表的配对误差评估；
4. 共洗脱数据集和第二柱复核；
5. 单糖组成、NMR 取代碳与 PMAA 连接位的一致性审核。

在完成上述验证前，平台定位仍是“候选生成与证据复核工作台”，不是自动确证系统。
