# 交付总览：多糖甲基化分析平台（PMAA）

## 一、做了什么

以 PMAA EI 质谱汇总表为参考库，按照 `甲基化平台开发计划` 搭建了一个**可运行、可回归、可追溯的研究原型**：

- **数据层**：SQLAlchemy ORM + 仓储封装，SQLite 已验证；PostgreSQL 仍需驱动、迁移、约束/并发和备份恢复验证。
- **导入层**：XLSX 只读解析，识别合并单元格 / 字体色 / 隐藏行列 / 注释语义，每个离子可追溯到源单元格。
- **化学层**：5 种骨架框架、`L = U \ M` 与 `A = {a,r} ∪ L` 确定性映射、氨基糖 N 位修正、位点相容性校验、同一 PMAA 多来源反解。
- **检索层**：定性离子检索（IDF 区分力加权）与数值谱匹配（加权余弦 + 反向匹配）**严格分离**；RT/RRT/RI 方法相容性检查。
- **分析层**：候选聚合 → 五维状态判定 → 证据上限 → 缺失证据 / 冲突 / 补测建议。
- **LLM 层**：Mock / OpenAI Chat / Responses 适配器，网关含超时、退避重试、Schema 一次修复、预算、缓存、回退；PV01–PV10 后校验。
- **报告层**：版本化快照，最小字段齐全，QC 失败仅出带标识草稿。
- **前端**：三步工作台（上传、检查谱图与峰、结果）+ 可选高级工具 + 顶部 LLM 配置，浅色主题，无构建步骤。
- **文件上传**：`POST /v1/imports/upload` + 前端拖拽/选择；支持 .xlsx/.xlsm/.csv/.tsv/.json，
  压缩包拒收不展开，按内容 SHA-256 去重保存。
- **一键启动**：`启动平台.command`（双击）与 `启动平台.app`（macOS 图标，可拖到 Dock）。

## 二、源数据实测结论

| 项 | 结果 |
|---|---|
| 布局 | 主导入区为 `Sheet1`：PMAA 122 行，m/z 66 列（59–275）；`Sheet2/3` 为补充结构与逐离子明细，不作为参考记录重复导入 |
| 分组 | 六碳糖 / 6-脱氧己糖 / 五碳糖 |
| 颜色 | 导入离子 1286 个：红色强峰语义 768 个、普通 `+` 518 个 |
| 注释 | R64 合并单元格：红色语义、`+` 语义、五碳糖只统计呋喃糖、**NaBD4 还原** |
| 导入结果 | 122 行 → 可用参考 83 · 人工复核 39 · 错误隔离 0 · **连接方式冲突 12**（均已隔离） |
| 化学实体 | 41 个，其中 **36 个存在多个原残基糖种来源**（多对一歧义，已全部保留） |

关键发现：`(2NAc)` 表示 C2 为 **N-取代**，必须从 O-甲基位剔除、且从可用位集合 `U` 中剔除。
新表中的 30 条氨基糖均进入专项复核。12 条 `T-*` 终端残基行把所有非甲基位写进“连接方式”，
与终端残基的化学补集推导冲突；平台保留其谱图与来源坐标，但不让它们进入普通参考区。

## 四·补 支持上传的文件格式

| 扩展名 | 用途 |
|---|---|
| `.xlsx` / `.xlsm` | PMAA 的 EI 质谱汇总表（只读解析，不执行宏） |
| `.csv` / `.tsv` | 已积分峰表 |
| `.json` | 峰表 / 结构化输入 |
| `.pdf` / `.doc` / `.docx` | 文档中的峰表或内嵌谱图；`.doc` 先本地转换；结果标为 derived |
| `.png` / `.jpg` / `.tif` / `.webp` / `.bmp` | 谱图图片辅助反解；必须人工校准 m/z 轴 |

**不接受** `.zip` `.rar` `.7z` `.gz` `.tar` `.bz2` `.xz` —— 平台不自动解压展开压缩包。
`.rtf` / `.wps` 暂不直接解析，请另存为 `.docx`。
单文件上限 50 MB；按内容 SHA-256 去重，同内容不产生副本、不覆盖原件。
格式矩阵由 `GET /v1/imports/formats` 提供，前端直接渲染，前后端单一数据源。

## 五、重要边界（不是缺陷，是规则）

- 参考条目来源为课程课件汇总表（E2 级，**未经本地标准实测**），默认状态 `reference_only`，
  因此当前库**不能**产出 `derivative_identity_level = confirmed`。这是符合计划要求的保守行为，
  升级路径是本地标准验证后置为 `locally_validated`。
- 定性离子表输入的证据上限为 `candidate`；无校准只输出面积占比；不输出 α/β、D/L。
- 原始 GC–MS 解析（M07）属计划 P4 范围，本版接受**已积分峰表**。
