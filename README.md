# 多糖甲基化结构解析平台（PMAA-Agent）

> 以 **PMAA（部分甲基化 alditol 乙酸酯）的 EI 质谱**为核心，把甲基化实验的峰表 / 定性离子表，
> 经确定性化学规则、谱库检索与 LLM 辅助评议，转化为**可复核的糖残基连接组成候选**。

本仓库是平台的完整源码（Python 分析内核 + FastAPI + 原生前端工作台）。

> ⚠️ 平台输出的是 **候选 + 证据 + 歧义 + 质量状态**，不是"自动确证结论"。
> α/β、D/L 构型与准确 mol% 不由常规非手性 GC–EI 甲基化分析产生；无校准不输出 mol%。
> 当前定位为 **V0.1+ / V0.2 研究原型**，参考库未经本地标准实测。

---

## 功能概览

- **七步串行向导**：建档 → 导入 → 提取峰值 → 峰候选审核 → 谱图比对 → 候选结构 → AI 评议 → 完成
- **多格式导入**：`.xlsx/.xlsm`（EI 汇总表）、`.csv/.tsv/.json`（峰表）、`.pdf/.doc/.docx`、质谱图（`.png/.jpg/.tif/...`）
- **谱图反解**：从图片 / PDF / Word 自动抽取峰（图像需人工校准 m/z 轴）
- **确定性判读引擎**：分子量门控（仅全扫描）、coverage 归一化评分、signature 离子惩罚、糖种优先排序、三段式可解释输出
- **保守证据原则**：近邻并列、缺失证据显式标注、无 NMR/保留证据不"确认"
- **离线可跑**：无 LLM 密钥时用 `mock` 适配器也能跑通全链路

## 快速开始

```bash
git clone git@github.com:hanmintao/PMAA-agent.git
cd PMAA-agent
cd pmaa_platform
./run.sh                      # 建虚拟环境 → 装依赖 → 建库 → 自动导入 EI 参考表 → 启动服务
```

启动后打开 <http://127.0.0.1:8000> 使用工作台；API 文档在 <http://127.0.0.1:8000/docs>。

> 端口被占用会自动顺延（如 8001…）。macOS 也可双击根目录的 `pmaa_platform/启动平台.command`。

### 运行验收用例

```bash
cd pmaa_platform
python tests/run_all.py       # 100 项：03/04 契约 + API、提取与数据隔离回归
```

## 核心科学规则（摘要）

1. 一条 PMAA 可对应多个原始残基；衍生物身份与原残基映射分别判定。
2. 定性离子表：`+`/红色**不换算为强度**，不做全谱余弦，证据上限为 `candidate`。
3. 未列出的离子 ≠ 未检出；缺测 / 未报告 / 明确未检出是三种状态。
4. 同一 PMAA 的多个来源必须全部保留，换柱或更高分数都不能恢复该信息。
5. 最高匹配分数不是正确概率；近邻并列必须同组。
6. 无校准只能给面积占比或半定量；检测器/积分方式与校准不一致时禁止输出 mol%。
