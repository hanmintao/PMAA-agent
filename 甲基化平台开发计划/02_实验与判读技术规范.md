# 多糖甲基化分析平台实验与判读技术规范

本文件为实验与判读部分的独立查阅副本。完整实验内容已并入[开发执行计划第14节](01_开发执行计划.md)，LLM辅助判定、接口、任务安排及最终需求整合见该主计划。后续实验规则变更应同步更新主计划与本副本。

本规范用于实现“实验数据→PMAA身份→糖残基连接候选→连接组成”的分析链。方法参数分为文献已报道的条件、平台拟定的试运行参数和本实验室验证后才能使用的放行阈值。任何给定文献的成功实例都不能替代新样品、新仪器和新色谱柱的方法转移验证。

## 1. 来源评估与前期资料修正

采用四级技术证据标记：E1为身份明确标准的本地原始数据、独立制备和校准；E2为已核对的原始论文方法/权威实验谱；E3为题录真实但仅摘要/片段可及或元数据不完整的资料；E4为专利、宣传或未独立验证的提议。等级用于本项目采纳，不是法定或通用行业分级。

| 来源 | 本次核验结果 | 可采纳内容 | 限制 |
|---|---|---|---|
| CCRC PMAA Spectral Database [1] | 官方页面及部分原始数值谱可核对 | PMAA结构、NaBD4标签、EI参考及残基映射 | 每个格子分别查实；有些只有示意图而无实测谱；不提供通用准确率 |
| Ďurindová等，1993 [2] | 期刊摘要确认专用PMAA谱库辅助检索 | 领域谱库建设方向 | 未核对全文的规模和性能；不能称现代自动平台已充分验证 |

| CN115406985A [8] | 说明书/权利要求为组成和连接指纹应用 | 单糖组成交叉核验、批次指纹 | 不作为自动PMAA判定算法的验证证据 |

两条前期链接应更正：Sims 2018正确PMID为[29525144](https://pubmed.ncbi.nlm.nih.gov/29525144/)；Li 2026正确PMID为[42035600](https://pubmed.ncbi.nlm.nih.gov/42035600/)。此前使用的29429600、41659749不对应这些论文。

以下内容不进入生产规则：

- 将氨水当作NaBH4/NaBD4的替代还原剂。氨水可作为介质，不能完成所需羰基还原。
- 将RRT比值容差写成分钟。RRT无量纲；RT才带时间单位。
- 将相对保留校正说成能够物理分离异构体。
- 对未活化的游离糖醛酸仅加NaBH4/NaBD4就宣称完成羧基还原。
- 将面积/分子量结果无条件视为准确摩尔量。此法在部分历史文献中确有使用，可保留为明示假设的半定量方法，不能替代响应校准。
- 把标准库制备中的“部分甲基化”移植到未知多糖样品。未知样品必须充分甲基化，否则产生伪连接位点。

Sims Table1流速单位在可核对原件中写作`cm/min`，不能擅自改成`mL/min`当作已确认条件。平台保留原始文本并标记单位疑点；下面采用2024文献明确记录的GC方法作为复现起点。

## 2. 样品登记与前处理

### 2.1 必填记录

样本编号、来源和批次；冻干/干燥方式；干基质量及其测量依据；单糖组成及方法/检出能力；糖醛酸、硫酸基和已知天然修饰；盐、蛋白及游离小分子情况；SEC结果；溶解状态；前处理损失；分析目的；仪器方法版本。未测项目标记unknown，不填0。

SEC单峰仅是均一性证据之一。聚合度分布相近并不意味着单一糖链序列。甲基化可分析连接组成，但不能把样本的一切异质性压缩成唯一重复单元。

### 2.2 前处理流程和质量门

| 步骤 | 操作与记录 | 质量门/处理 |
|---|---|---|
| 样本分路 | 测单糖组成、糖醛酸和硫酸基；调查天然O-Me/O-Ac、氨基糖和果糖 | 中性醛糖走N路线；其余进入专项分支；未知修饰提示待查 |
| 去小分子/脱盐 | 已纯化样本按分子量选择透析/超滤；记录膜MWCO、时间、换液和回收 | MWCO不能高到丢失待测组分；保存透出液/滤液用于损失检查 |
| 去杂 | 仅在有证据需要时去蛋白、色素等；记录前后总糖和组成 | 不进行会删去目标糖组分的例行除淀粉/强处理 |
| 干燥 | 冻干后保存密封，记录称量和残余水/盐风险 | 实际质量不能默认全是糖；DMSO与试剂水含量按具体SOP管理 |
| 溶解/分散 | 按N路线DMSO中加热分散；拍照/记录不溶物 | 不溶不能仅靠延长甲基化时间掩盖；评估另一溶解路线 |
| 对照 | 全流程空白、标准多糖、样品独立制备重复；必要时加标 | 后处理分装重复和独立全流程重复分别编号 |

不要把“越无水越好”写成跨方法规则。DMSO、MeI、碱的加料顺序和水含量共同影响反应，文献已讨论特定无水/加料条件导致的副反应。[9] 本方案锁定所选方法顺序；不在缺验证时改变次序或跨方法拼接。

## 3. 中性醛糖路线N：可复现的文献起始SOP

以下衍生化条件保持Bajwa等2024中性标准分支与其引用的§3.3流程一致。[5] 约10mg是起始总量，后续分成四份；不应把缩小为1mg的版本自动标记为同等验证。原文的“室温”和“过夜”需要在本地转移时具体化，建议先记录20–25℃、16±1h作为平台试运行设置，并验证后锁定。

| 顺序 | 文献起始条件 | 平台须记录的关键参数 | QC与异常处理 |
|---|---|---|---|
| N1 DMSO分散 | 约10mg样品，2mL DMSO，60℃搅拌过夜；PTFE衬盖玻璃管、N2顶空 | 实际量、时间、温度、试剂批次、溶解状态 | 明显不溶物记录并审核；可能需要专门溶解优化 |
| N2 碱处理 | 冷却室温；新鲜研磨NaOH约200mg，搅拌2h | 加料顺序、温度、时间 | 先NaOH后MeI；不得省略冷却或随意改顺序 |
| N3 甲基化 | MeI 1.2mL，室温避光搅拌3h | 实际体积、起止时间、反应异常 | 全流程空白与标准同时处理；不足时验证补充甲基化 |
| N4 分配清洗 | 冰上加入DCM 3mL；10%乙酸水溶液5mL×2，水5mL×2；保留下层DCM，蒸干 | 每次体积、分相、损失 | 此处只适合中性分支；带电/硫酸化样本不能照此弃水相 |
| N5 分装 | 甲醇8mL溶解，分为4管各2mL，再蒸干 | 每份理论原样当量约2.5mg | 分装不等于独立甲基化重复；预留份用于复测 |
| N6 水解 | 每管2mL 4M TFA，100℃4h；冷却、N2吹干 | 酸浓度、时间、温度、管型及密封 | 酸敏感糖须另法；除酸不充分会干扰后续还原 |
| N7 还原 | 新鲜NaBD4水溶液10mg/mL，2mL，室温搅拌过夜；冰乙酸逐滴淬灭至不再起泡，吹干 | NaBD4同位素规格、批次、浓度、时间 | 醛糖C1引入D；过量还原剂须完全处理；标签未知则不跨标签确认 |
| N8 乙酰化 | TFA 0.25mL＋乙酸酐1.25mL，60℃1h；冷却、蒸干 | 各体积、反应时间、干燥情况 | 与标准比对；强酸可能造成特定糖损失，需做标准回收验证 |
| N9 净化 | DCM3mL；饱和NaHCO3水3mL×2、水3mL×3；有机相经无水Na2SO4，吹干 | 分相和清洗次数、样本损失 | 初始中和放气结束前不密闭；避免水盐进GC |
| N10 复溶进样 | 乙酸乙酯复溶 | 原文未给复溶/进样体积；平台试运行可从0.5mL与1µL开始，须验证线性及不饱和 | 不能把这些补定参数标成原文已验证值；稀释倍数必须入库 |

MeI、强酸、强碱和乙酸酐步骤由受训人员依机构通风、控温及废液SOP执行；NaBD4淬灭、碳酸氢盐洗涤存在放气。原始资料的反应容器与操作条件须在实验室审核后转为正式SOP。

### 3.1 甲基化完全性

FTIR羟基区变化可作支持，不能单独证明所有残基充分甲基化。最低检查组合为：溶解/分相记录、空白、已知标准、全乙酰化副产物、独立制备重复，以及新基质的一轮与补充甲基化比较。

建议试运行比较主要连接组分的一轮/二轮差异是否落在已测重复性范围；在缺少统计分布前可用“变化超过10%相对值或2个百分点”的较大者作为调查触发值，不能作为普适合格标准。补充甲基化后支化候选系统下降、对应少取代衍生物上升，首先怀疑原先欠甲基化。

全乙酰化衍生物也可能来自高度取代、特殊修饰或共洗脱，不以单一峰自动判全批失败。

### 3.2 水解、还原、乙酰化稳健性

在同一批甲基化产物分装上进行水解时间挑战；以4M TFA/100℃/4h为复现点，可选2h、4h、6h作为方法开发条件。该矩阵是本项目设计，选择最终条件应根据标准回收、残余聚合物、关键峰比例及降解产物，而不是只看总峰面积最大。

对还原或乙酰化不完全的疑似样本，用标准及分装样本进行补充反应实验；补充后目标峰继续系统增加则原条件未达稳态。硼酸盐残留、残余酸和水分别记录；如采用甲醇共蒸除硼等额外处理，应登记为新的方法版本并验证回收，不能不留痕迹地插入原文SOP。

## 4. 专项分支

### 4.1 糖醛酸路线A

任意已证实的糖醛酸存在都需要评估，不能因低于10%就按“无糖醛酸”处理。目标是先将羧基转为带C6标签的中性糖等价物，再进行连接分析；还原效率必须通过前后组成验证。

可作为方法开发起点的毫克级羧基还原实例来自Wustman等1997的CMC活化流程：[10]

| 步骤 | 已报道起点 | 转移时的质量要求 |
|---|---|---|
| 活化 | 约5mg样本溶于5mL水，pH4.75；水溶性CMC60mg，搅拌约2h，并维持pH4.75 | CMC明确为水溶性碳二亚胺试剂，不是羧甲基纤维素；不得按相同质量改成EDC |
| 还原 | 加冷4M imidazole缓冲液350µL，pH7.0；NaBD4 35mg，5℃搅拌1h | 记录实际pH、温度和试剂纯度；不把普通NaBD4水溶液当游离羧基直接还原方法 |
| 后处理 | 乙酸终止至约pH5.5；约5℃水透析40–50h，冻干 | 根据目标分子量选择膜并核对回收，透析膜规格不能从其他路线机械移用 |

该实例不是对所有酸性多糖、天然甲酯化程度和本平台下游条件的共同验证。正式酸性模块必须使用已知GalA/GlcA来源的标准检查还原前后总量，必要时重复还原。初始目标可设残余糖醛酸相对原始含量≤5%，同时检查对应中性糖增加与总回收；这是项目放行目标，若检出能力不足则不能据此宣称达标。需要区分天然甲酯化与游离羧基时，采用专门的顺序标记路线并重新验证，不从这条总还原路线推算甲酯化位点或程度。[3,11]

羧基NaBD4还原形成C6的6,6-d2；水解后再NaBD4还原则醛糖C1再引入D，两次标签必须分别记录。原中性Gal与GalA还原产物可能共洗脱，含C6的相应离子有+2差异。Sims展示4-Galp/4-GalpA的233/235离子对；必须校正天然同位素、标签纯度及离子串扰，不能以单个235峰直接算GalA比例。[3]

### 4.2 其他专项分支

| 样本特征 | 必须改变或补充的实验 | 平台处理 |
|---|---|---|
| 硫酸化 | 盐型/溶解性处理；必要时原样与经验证脱硫样配对分析；检查脱硫时断链 | 未甲基化位点可能是硫酸取代而非糖苷连接；禁止直接当支化位点 |
| 天然O-Me | 需要区分天然和新增甲基时使用CD3I等标记路线 | 分开记录OCH3/OCD3和相应碎片；普通CH3I数据不确认天然甲基位置 |
| 天然O-Ac | 常规强碱会去乙酰；若研究原位乙酰需专用保留/对照方法 | 常规结果不包含原始乙酰位置的可恢复证据 |
| 果糖/果聚糖 | 酸敏感、C2还原标记、还原产生多个糖醇；专门温和水解 | 不套醛糖C1或单一衍生物规则；配对组分不能误计为两个原残基 |
| 3,6-内醚糖 | 标准TFA流程可能破坏；文献采用还原性水解与常规NaBD4分路 | 不同还原方法的谱库隔离；方法不能互换 |
| 氨基糖 | 明确N-乙酰/N-甲基状态和水解回收 | C2不是普通O-甲基位；旧表把“2-Me”笼统列入O-Me的条目隔离审核 |
| 难溶/强结晶多糖 | 验证分散和充分甲基化；避免只靠强酸补救 | 超出验证范围时仅研究性结果 |

这些分支可在数据库中提前建模，但只有完成专项实测验证的分支才能签发对应的自动确认结果。

## 5. GC–EI–MS方法及保留规则

### 5.1 同源复现方法

采用2024文献§3.5作为第一套完整复现方法：[5]

| 参数 | 条件 |
|---|---|
| 色谱柱 | Supelco SP-2380，60m × 0.25mm × 0.2µm |
| 温程 | 55℃起始；20℃/min至170℃；0.3℃/min至190℃；3℃/min至215℃，保持20min |
| 进样口 | 250℃；GC–MS分流比10:1 |
| 载气 | He，恒流0.8mL/min |
| EI/源温 | 70eV，离子源230℃ |
| 四极杆/传输线 | 150℃/280℃ |
| 扫描 | m/z45–350；4.59 scans/s；原文溶剂延迟12min |

这套慢温程适合作为参考复现，升温与保持约101min，另加进样准备/冷却。加速方法属于单独开发任务。原文12min溶剂延迟必须用最早洗脱标准核验；在自建方法中若遮蔽目标峰应修改并登记方法版本。

扫描频率必须按实际峰宽检查，平台拟以最窄待定量峰至少约10个采样点作为初始目标。不得把4.59 scans/s当任意快色谱的固定充分值。主柱可换为实验室已有HP5-ms、DB-23等，但需重建保留库和近邻分离验证；第二柱选择以实际混标的选择性改善为依据。

### 5.2 RT、RRT和RI

`RT`带单位；`RRT = RT(PMAA)/RT(参照物)`无量纲；`RI`须注明算法及同批标准。程序升温与等温的保留指数算法不得混写。内参必须记录化学形式和加入阶段：myo-inositol hexaacetate用于保留参照时，不能把甲基化前加入的游离myo-inositol默认视作同一物质。

文献值只在条件相容时支持候选排序。生产确认使用本方法标准的分布；初始可采用中心±3个标准差并考虑批次漂移和最小测量误差，最终由近邻异构体盲测确定。不能将该窗口转换为“距标准最近即确定”。

Sims Table1的例子：2,4-di-O-methyl Man/Glc在BPX90的RRT约0.826/0.825，而HP5-ms约0.901/0.887。该例说明第二柱可能提供新选择性，不能把这些数值套到SP-2380。其他列如2,3,6-Me3 Glc约0.737(BPX90)/0.759(HP5-ms)也仅为方法特异参考。[3]

## 6. PMAA与原连接位点的映射

### 6.1 适用框架和计算规则

对未修饰醛糖，定义`a`为原异头碳，`r`为原成环氧所连的非异头碳，`U`为原残基可具有游离羟基或受体连接的碳位集合，`M`为观察到的O-Me位置。则在充分甲基化、没有其他取代的前提下：

```text
受体连接位置 L = U \ M
PMAA中O-Ac位置 A = {a,r} ∪ L
```

对常见醛糖a=1；原环氧位置在水解开环后也被乙酰化，不能误判为连接位点。对酮糖、氨基糖、硫酸化或带其他修饰的残基，这一简式不能直接使用。

| 框架 | U | r | 说明 |
|---|---|---:|---|
| 醛己吡喃糖Hexp | {2,3,4,6} | 5 | Glcp/Galp/Manp等 |
| 醛己呋喃糖Hexf | {2,3,5,6} | 4 | 环型不同，缺甲基位置解释改变 |
| 醛戊吡喃糖Pentp | {2,3,4} | 5 | Xylp/Arap等 |
| 醛戊呋喃糖Pentf | {2,3,5} | 4 | Araf等 |

### 6.4 必须保留的多对一来源

4-Arap与5-Araf都可形成相同的1,4,5-tri-O-acetyl-2,3-di-O-methyl arabinitol；CCRC两种来源对应同一谱图文件。[12] 同一己糖骨架的4-Hexp与5-Hexf也可形成相同的1,4,5-Ac3-2,3,6-Me3糖醇。在同位素和立体条件相同时，这属于同一衍生物的不同原始来源。

因此即使与纯标准共进样、全谱一致，也可能只能确认PMAA，不能确认原环型/连接来源。第二根GC柱、EI解卷积或更高匹配分数都不能恢复已丢失信息。应返回原残基候选集合，并由NMR环型证据等解决。

### 7.2 碎片和同位素规则

PMAA的EI解释以糖醇碳链断裂及后续碎裂为基础，记录碎片的原子来源和标签保留情况。若没有足够证据建立完整碎裂机理，规则库可先保留“实测支持离子”，不要给每个峰编造机理。

醛糖NaBD4还原主要在C1加入D，只有保留相应标记的碎片相对NaBH4有相应质量差；不能将整条谱所有m/z统一加1。羧基还原的C6-d2另行处理。需分别保存还原前、羧基还原、异头还原以及CD3I甲基化等步骤。

Sims的Xylp例子展示2-Xylp与4-Xylp相关衍生物在NaBH4路线难以区分，而NaBD4标签可利用189/190等离子差异提供证据；存在共洗脱时仍须校正互相贡献和同位素串扰。[3] 数学上只有响应矩阵可辨识且经过混标验证，才允许分开定量。

### 7.3 两种输入模式

| 输入模式 | 允许的算法 | 禁止的推断 |
|---|---|---|
| qualitative_ion_list：+、红色强峰或简单离子集合 | 标签/骨架相容过滤、按区分力加权的离子覆盖、候选并列 | 把+设为100、用伪强度计算余弦、把未列离子当缺失、输出准确概率 |
| numeric_spectrum：m/z与数值强度 | 背景扣除、适度归一、加权余弦/反向匹配、鉴别离子和离子比检验 | 只看最高分、忽略共洗脱/保留/标签、将全谱分数直接当正确概率 |

初期不设一个通吃所有糖种的“分数≥800就确认”。定性模式权重、数值模式匹配阈值、离子比范围和近邻分差由独立标准验证集确定并版本化。验证前系统可排序，确认仍依赖真实标准及审核。

## 8. EI汇总表导入流程

1. 保存原文件、SHA-256、文件名和导入时间；只读解析。
2. 检测工作表、合并单元格、隐藏列、字体/填充颜色、表头和说明文字；展示预览。
3. 核实“红色”的实际语义。仅当原表说明明确时记录为如`reported_gt20pct`；不换算成固定数值强度。
4. 规范PMAA名、原糖名、环型、O-Me、O-Ac、N修饰、NaBD4/NaBH4及来源字段；原始文本同时保留。
5. 校验位点范围：例如普通Glcp不能有C5 O-Me；Fucp/Rhap不能有C6 O-Me；氨基糖C2不作为普通O-Me。
6. 对源表写出的“连接方式”重新做化学映射并比较。冲突进入隔离队列，不以源表列自动覆盖规则。
7. 多来源同名记录保留各自谱图，不把互相矛盾的离子/强度拼成一条“超级谱”。
8. 来源缺失、标签未知、只有离子集合的条目可进入候选库，但不可充当生产确认/定量标准。
9. 人工审核后发布参考库版本；分析记录绑定该版本，后续修改触发差异报告。

最小参考记录：`source_row_id, derivative_name_raw, parent_sugar, ring_form, o_methyl_positions, o_acetyl_positions, nitrogen_modifications, reduction_label, evidence_type, ions, source_locator, method_metadata, review_status`。数值谱另有归一方式、扫描覆盖、测量/提取来源；色谱观测另存method_id和参照物。

当前未收到拟上传的EI汇总表；可见的既有参考资料只用于接口和错误模式设计，不等于本项目数据已经验收。

## 9. 原始谱处理与结果判定

### 9.1 数据处理顺序

```text
文件完整性 → 方法/标签检查 → 空白/调谐/饱和检查
→ TIC与EIC构建 → 基线和峰检测 → 共变离子归组/解卷积
→ 数值EI候选 → 同方法保留核查 → 结构映射与组成一致性
→ 定量与样本QC → 人工复核 → 版本化报告
```

保留原始扫描和所有处理参数。基线校正不得消去真实低丰度鉴别离子；质心化/取整容差依仪器质量精度验证，不能在高分辨数据上直接无记录地取整数。单位、保留时间轴和强度积分要与原厂软件在测试文件上核对。

共洗脱模型可写为`Y(t,m) ≈ Σ A_k(t) S_k(m) + B(t,m)`。要求非负、合理峰形、有效残差和稳定解。如果两组分没有可区分的谱/保留信息，模型并不可辨识，必须保持组合峰；不能因算法返回两个系数就宣称物理分离成功。

### 9.2 判定状态

| 维度 | 状态与含义 |
|---|---|
| qc_status | passed / warning / failed / not_assessed |
| derivative_identity_level | confirmed：同方法真实标准、完整EI、保留和质量门支持；probable：强支持但确认条件不齐；candidate：证据有限或并列；unknown：没有可辩护候选 |
| residue_mapping_level | resolved：适用前提下唯一；ambiguous：同一PMAA有多个来源；unsupported：缺少映射适用条件 |
| quantification_level | calibrated_molar / semiquantitative / area_only / unavailable |
| review_status | automated / human_reviewed |

`confirmed`针对衍生物身份，不自动将原残基映射变成resolved。仅EI汇总表的候选上限不因高分突破；批次QC失败则禁止正式报告签发，但保留研究性结果。

## 10. 定量与样本级检查

### 10.1 校准定量

优先使用与实际检测器、积分方式相同的PMAA标准校准。内标模型可定义：

```text
y_i = A_i / A_IS
x_i = n_i / n_IS
y_i = a_i + b_i*x_i
n_i = n_IS * (y_i-a_i)/b_i
mol%_i = 100*n_i / Σ n_j
```

`A_i`是与校准一致的TIC、FID或选择离子面积，不能混用。内标加入最终样品只评价进样/检测，不验证前处理回收；全流程损失由独立标准制备和过程对照评估。天然同位素及标记串扰需在进入定量前校正。

未校准可以报告面积百分比；历史面积/分子量换算另标`semiquantitative`并注明假设，不作为准确mol%。组合峰缺少可分解响应时不强行分摊。未识别峰只能报告其可测面积贡献，不能编造未知组分的摩尔占比。

分母明确写为“已鉴定且在校准范围内的PMAA总摩尔量”；不能让这种归一化看起来覆盖了原样所有残基。分别报告未识别面积比例、低于LOQ组分、未覆盖的专项糖和样本回收。

### 10.2 端基—支化检查

对无环、普通单异头连接、所有残基和还原端均正确计入的糖链森林，设`n_k`为有k个非异头受体连接位的残基数，C为链数，则：

```text
n_0 = C + Σ(k-1)*n_k   (k≥2)
```

当聚合度高、主要为双受体支化时，才近似出现端基数与支化点数接近。低聚物、还原端处理、环状链、双异头连接、修饰、欠甲基化和定量偏差都会改变解释。平台把平衡偏差作为调查信号，不硬性要求所有样品端基:支化=1:1，也不为了“闭合”篡改峰面积。

单糖组成比较需统一中性/糖醛酸还原折算、回收和分母。PMAA提示微量Gal而组成未检出时，先看组成分析的检出限和水解回收，不能立即删掉Gal候选。

## 11. 歧义处理表

| 情形 | 可解决手段 | 不能做的事 |
|---|---|---|
| Glc/Gal/Man同连接EI相似 | 本地同柱标准、相容组成、第二柱 | 单靠EI给糖种唯一判定 |
| 同糖不同连接共洗脱 | 诊断EIC、混标校正、第二柱或经验证解卷积 | 重复分配共享离子的全部面积 |
| 相同PMAA来自不同原环型/连接 | NMR环型/独立结构证据 | 声称换柱可区分同一化合物的来源 |
| D/L对映来源 | 独立手性分析或来源确证 | 非手性GC–EI直接给D/L |
| α/β来源 | NMR/酶学等独立证据 | 从PMAA峰形/保留补异头构型 |
| NaBH4与NaBD4混库 | 按原子标签分库、重新测标准 | 全谱统一+1修正 |
| 糖醛酸还原物与中性糖共洗脱 | C6标签离子及同位素响应矩阵 | 仅凭RRT分开 |
| 欠甲基化伪支化 | 补充甲基化、标准/回收检查 | 将额外乙酰位全部解释为真实连接 |
| 硫酸/天然修饰占位 | 专项对照、标记及NMR | 直接套无修饰糖补集公式 |
| 只有少量离子/没有保留 | 多候选报告，列补测需求 | 编造谱强度或准确置信度 |
